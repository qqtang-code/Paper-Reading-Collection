# FreeToken · 论文精读

**FreeToken: 边缘原生的 MoE 服务系统(Bandwidth-Adaptive Execution)**(arXiv:2608.16157)

> 把个人电脑变成统一的弹性推理平台:带宽自适应执行让 8GB 显存笔记本跑 35B 模型、游戏台式机跑 284B、单张工作站 GPU 跑 753B GLM-5.2,且快到能支撑真实 agent 负载。
>
> FreeToken treats the consumer PC as one elastic inference platform: bandwidth-adaptive execution puts a 35B model on an 8GB laptop, 284B on a gaming desktop, and the 753B GLM-5.2 on a single workstation GPU — sustaining real agent workloads (39.3 tok/s coding-agent decode on the 8GB laptop; TTFT tails under 44 s where every baseline blows past 150 s).
